# 🍷 Ma Cave à vin

Application web perso pour gérer ma cave : inventaire, emplacement de chaque bouteille dans les casiers, régions/appellations, garde, statistiques et historique des bouteilles bues.

- Fonctionne hors connexion, s'installe sur l'iPhone (Safari → Partager → Sur l'écran d'accueil).
- Les données restent sur l'appareil (localStorage) — penser à exporter une sauvegarde de temps en temps (Réglages).
